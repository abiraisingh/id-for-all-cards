# 🪪 NeoID for the Homeless People  

> **NeoID** is a decentralized digital identity management system designed to empower homeless and unregistered individuals by giving them secure, blockchain-based digital identities.

---

## 🌍 Overview

**NeoID for the Homeless People** aims to bridge the identity gap by providing a **trustless, decentralized**, and **biometrically verified** digital ID system.  
Using **blockchain** for transparency and **biometrics** for uniqueness, NeoID ensures that every person — even without official documents — can have a verifiable and secure identity.

---

## 🚀 Features

- 🔐 **Decentralized Identity Management** using blockchain smart contracts.  
- 👆 **Live Fingerprint Capture** via browser or connected sensors.  
- 😊 **Facial Recognition** and data encoding for real-time user verification.  
- ⚙️ **Secure Node.js + Express Backend** handling blockchain and API logic.  
- 🌐 **Responsive React + TypeScript Frontend** for smooth user experience.  
- 🪙 **Immutable Identity Records** stored and verified through blockchain.  

---

## 🧱 Tech Stack

| Layer | Technologies |
| :----- | :------------ |
| **Frontend** | React, TypeScript, CSS |
| **Backend** | Node.js, Express.js |
| **Blockchain** | Solidity, Ethereum / Polygon |
| **Database / Storage** | IPFS, MongoDB |
| **Biometric Capture** | Web APIs, Fingerprint SDKs |
